AI職業適性テスト iPhone PWA版（Windows 11制作・配布用）

【重要】ZIPをiPhoneにコピーして開くだけではPWAになりません。
HTTPS対応のWebサーバーで公開する必要があります。

手軽な公開例：GitHub Pages
1. GitHubで新しい公開リポジトリを作成
2. このフォルダーの中身（index.htmlなど）をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch → main / (root) → Save
4. 発行された https://...github.io/.../ をiPhoneのSafariで開く
5. Safariの共有メニュー → ホーム画面に追加

【重要なプライバシー注意】
公開リポジトリには固定宛先メールアドレスがコードに含まれます。
閲覧者がHTMLソースを調べると宛先を確認できます。
公開リポジトリに個人情報をアップロードしないでください。
受験者データはiPhoneのブラウザ内に保存され、Webサーバーには送信しません。
ただしメールアプリを開いて送信すると、通常のメールとして本文が送信されます。
データは端末/ブラウザごとに別管理で、他端末との同期はありません。
Safariのサイトデータ削除などで保存データが消える可能性があります。

【メール】
送信ボタンで宛先・件名・本文入りのメール作成画面を開きます。
メール送信は利用者がメールアプリ側で確定してください。
iOSでGmailを利用する場合はiPhoneの設定でGmailを標準メールアプリに指定します。
メールアプリやiOSの仕様によっては内容が引き継がれない場合があり、実機テストが必要です。

【GPS】
Safariで位置情報を許可した場合のみ端末内の記録に緯度経度を保存します。
管理画面の地図表示はインターネット接続が必要です。

【フォルダー】
1：ホーム背景 / 2：アイコン / 3：共通背景 / 9：履歴書背景
背景を使う場合は各フォルダーに画像を置き、image_manifest.jsのファイル名を設定してください。

【検証】
ファイル生成とJavaScript構文を検証。iPhone実機での起動・メール連携は未検証。
